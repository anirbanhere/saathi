# Bounded cached native read validation

Previously savedPlanRead parsed persisted JSON and cast it to ReadResult without checking its target, shape or mock/draft semantics. Corrupted rows could claim a foreign task, live evidence or verified manual output, and malformed JSON escaped as a raw parse failure. The cached path now validates evidence before returning it, preserving existing valid cached/restart/cancellation behavior.

A SQL CASE accepts only text payloads of at most64,000 UTF-8 bytes before materialization in JavaScript. Strict schemas enforce the exact read-only envelope, target ID, bounded unique step IDs, safe timestamps, known tools/statuses, bounded strict outputs and aggregate priority. Mock clinic output has only mock slots with completed/unavailable matching availability. Unskipped manual output must be an unverified draft requiring user action. Skipped steps carry a reason/requires_user_action; unskipped failure reasons apply only to clinic lookup. Unknown fields, live markers, positive verification, mismatched aggregate status, duplicate steps, BLOBs, malformed/oversized data and foreign targets fail with a fixed503 message.

The invalid row is retained. No repair, deletion, overwrite, automatic retry, adapter replay, quota release, new receipt or migration follows. Ownership remains established by TaskPlans before this internal helper; no new route or public grant is introduced. Cache validity does not grant execution, prove external truth, cryptographically authenticate the SQLite file, or bind every coherent observation field to the original plan/date. Context/content binding and remote-provider authentication remain separate work. Public/source schema, approval/spend/speech/channel gates and the separately pinned3b81c85 rollout candidate are unchanged.

Regression first reproduced corrupt cache acceptance, then focused cache/native reads7/83 pass. Mutations include wrong target/mode/tool/verification/status, extra fields, duplicate steps, malformed/oversized/BLOB payloads and impossible manual failures. Usage/events and raw retained payload are unchanged. Valid restoration returns cached evidence, and corrupt mock cache invokes no second lookup. Fresh-context adversarial review found an impossible unskipped-manual failure combination; tightening it and a regression closed the gap, follow-up found no additional issue. Cross-model skipped non-interactive. Full suite/types/build evidence is in HANDOFF; no browser change/provider call or real data used.
