# Explicit localized Help console

Development source now offers Help in your language with English/Hindi/Tamil selection and a Show help button. This is the smallest UI part of tasks/help-status-console.md: per-card exact-target status controls are now documented in task-status-console.md. It neither classifies arbitrary chat nor enables voice, channels or generic mutating intents. Source15/public7 and existing profiles/deployment are unchanged.

The module installs listeners without making requests. An explicit click captures the selected locale and uses the existing authenticated api()/CSRF helper for one fixed help POST. Shared run() busy/focus handling freezes the locale and suppresses overlapping clicks. Successful guidance receives its locale's lang attribute and focus; shared status reports localized Help loaded / No task was run, preserving other actions' default messages. Failed requests render fixed localized unavailable/expired-session text, never raw server/provider errors, and restore controls for an explicit later attempt.

The component checks returned format/intent/locale/action_executed=false and a nonblank message of at most6000 characters before rendering with textContent. HTML-like strings remain text. A20-second request deadline aborts and suppresses late/uncooperative responses without retry. The existing JSON parser is reused; the client message bound is applied after parsing the server's fixed small help response, not a new streaming-body guard. No model/catalogue/provider probe or task/usage mutation occurs. The new module has fixed served-asset/build allowlist entries.

Help copy now directs users to task panels rather than requesting implementation IDs. The backend structured target contract is unchanged and documented separately. This console does not fetch status or call/refresh legacy appointment get/list, which can write expiry/audit. A future status action must preserve that separation and use already-rendered owned IDs. Configuration guidance is not independently verified account availability; native fluency/voice acceptance remains unmeasured. Navigation labels are not a complete localized application UI.
