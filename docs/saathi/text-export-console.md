# Explicit text download console

The development console now has **Download my text** below reviewed preferences. It explains that the file contains this workspace's conversation/preference text, may be sensitive, and excludes tasks, audio, usage records and backups. It does not claim account backup or deletion. The existing owner/CSRF export API and source schema15 remain unchanged; the public schema7 demo has not been redeployed.

The click uses the shared busy/focus guard, including duplicate-click suppression and keyboard activation. Other actions keep their existing success wording; download success says **Download requested. Check your browser’s downloads and keep the file private.** This reports the request rather than asserting that a file was saved. The browser controls the ultimate download behavior, and the anchor's filename is a proposal ([MDN download](https://developer.mozilla.org/en-US/docs/Web/API/HTMLAnchorElement/download)).

`export.js` makes one fixed same-origin no-store POST with the current CSRF value and the sole scoped body. Redirects fail, errors have fixed messages and no provider/server error text is reflected. There is no request on startup, enter, refresh, reload or recovery; no automatic retry or transmission of the resulting file to a model/cloud service. Network/session/unsupported/size/server failures leave the controls usable for an explicit later choice.

The helper bounds declared and streamed response bytes to2000000, rejects unsupported MIME, invalid UTF-8/JSON or wrong version/scope/completeness and checks the expected text collections before producing a Blob. The backend remains responsible for complete row/ownership validation. A20-second deadline aborts/cancels reads and suppresses late or uncooperative replies. No partial file or fallback is emitted. This adds no payment/channel/speech permission or model call.

The filename is fixed saathi-text-export.json. A temporary native anchor is removed after activation; the object URL is revoked after30 seconds to allow the downloader to consume it, or immediately if click setup fails. [Object URLs](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static) retain their referenced object until released; [revocation](https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static) releases that reference. Thirty seconds is this application's bounded cleanup choice, not a cross-browser completion guarantee. Downloaded files/earlier copies cannot be recalled or erased by server deletion. No browser storage or service worker caches the exported data.
