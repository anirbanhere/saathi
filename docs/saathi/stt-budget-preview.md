# Offline speech budget preview contract

This increment is a pure internal preview, with no runtime route, database migration, provider registration, storage, reservation, claim or execution. Existing fixture limits/claims remain fixture-only. It composes the canonical tariff calculator; it does not accept a client-supplied cost estimate.

`createSttBudgetPreview(reviewedProfile, tightenedLimits?)` copies strict trusted profile data into a closed evaluator. Missing/nonliteral enablement denies by default; invalid configuration returns fixed denials. The profile pins revision, opaque provider-account reference, complete tariff, permitted en/hi/ta language hints, maximum bytes/duration, freshness window and hard owner/global attempt/audio/lifetime-record/money ceilings. Optional overrides may only tighten reviewed ceilings. Neither these settings nor a positive preview authorize live access or paid tests.

The evaluator accepts owner context separately from trusted inspected media metadata, usage snapshot, balance snapshot and explicit clock. Media cannot carry owner/provider/model/limits overrides. Usage must match provider/currency/owner/account/policy revision and current UTC day, with nonnegative safe counters and consistent global totals. Usage and balance evidence must be fresh and not future-dated. Balance must match the pinned provider/account/currency; outstanding reservations across all days are subtracted before comparing the new estimate. Unknown balance denies. Both current usage and prospective increments must fit the effective ceilings; one pending owner denies a new preview.

Usage must aggregate the provider account across prior model/tariff/policy revisions. `policyRevision` identifies the rules used to assemble/check this snapshot; it must never partition the durable ledger or reset spent units when configuration changes. Outstanding balance reservations likewise include all owners/revisions/days for this account. Audio quotas use inspected rounded duration, while monetary quotas use the tariff's possibly larger billable duration. No snapshot is authenticated or generated by this module.

Successful output is frozen scalar `budget_preview` evidence with pinned identity and estimated cost, never approval, a lease or funds reservation. The evaluator does not authenticate these trusted snapshots, discover vendor balances/prices, check actual bytes/consent or serialize concurrent callers. A future executor must obtain authoritative evidence and recheck/reserve atomically, including unknown external costs and concurrent account activity. Repeated previews do not consume or refund units. No full admission/cost guarantee, provider or model quality is established by synthetic tests.

Verification must cover default denial, tightenable caps, precise prospective boundaries, missing/stale/future/mismatched evidence, pending ownership, inconsistent counters, integer safety, strict override rejection, frozen scalar projection and input mutation isolation. Use synthetic tariffs/snapshots only. Durable storage, consent/claim integration, remote reconciliation and actual provider access remain separate work in tasks/live-stt-admission-design.md.
